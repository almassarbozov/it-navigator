# Как помочь проекту

Спасибо за интерес к IT Навигатору.

1. Создайте fork репозитория.
2. Создайте ветку: `git switch -c feature/short-name`.
3. Внесите одно логически цельное изменение.
4. Запустите `npm test` и `npm run check`.
5. Сделайте commit с понятным сообщением и откройте Pull Request.

Для новой профессии добавьте понятное описание без рекламных обещаний, четыре базовых навыка, пробный проект и план на четыре недели.
