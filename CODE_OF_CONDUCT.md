# Кодекс поведения

Мы хотим, чтобы проект оставался дружелюбным и безопасным местом для обучения. Общайтесь уважительно, критикуйте идеи, а не людей, помогайте новичкам и не публикуйте чужие личные данные. Оскорбления, дискриминация и травля недопустимы.

О проблемах сообщайте владельцу репозитория через приватный канал, указанный в профиле GitHub.
