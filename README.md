# IT Навигатор

Интерактивный образовательный сайт для тех, кто хочет разобраться в IT-направлениях и выбрать понятный первый шаг.

## Что внутри

- 8 карточек профессий с задачами, навыками и пробным проектом;
- фильтр направлений по типу работы;
- тест из 6 вопросов с тремя персональными результатами;
- динамический план старта на 4 недели;
- адаптивный и доступный интерфейс;
- автоматические тесты и публикация на GitHub Pages.

## Быстрый старт

Нужен [Node.js 20+](https://nodejs.org/).

```bash
git clone https://github.com/YOUR_USERNAME/it-navigator.git
cd it-navigator
npm run dev
```

Откройте `http://localhost:4173`. Зависимости устанавливать не нужно.

## Проверка проекта

```bash
npm test
npm run check
```

## Публикация на GitHub Pages

1. Создайте пустой репозиторий `it-navigator` на GitHub.
2. Загрузите в него файлы проекта и отправьте ветку `main`.
3. В репозитории откройте **Settings → Pages**.
4. В поле **Source** выберите **GitHub Actions**.
5. После выполнения workflow адрес сайта появится во вкладке **Actions** и в настройках Pages.

## Как устроен код

```text
.
├── index.html          # разметка приложения
├── styles.css          # дизайн и адаптивность
├── src/
│   ├── app.js          # интерфейс и взаимодействия
│   ├── core.js         # чистые функции
│   └── data.js         # направления и вопросы теста
├── tests/              # автоматические тесты
└── .github/workflows/  # CI и GitHub Pages
```

## Образовательные идеи для доработки

- **Начальный уровень:** добавьте девятое направление в `src/data.js`.
- **Средний уровень:** сохраняйте результат теста в `localStorage`.
- **Продвинутый уровень:** добавьте сравнение двух профессий и URL-параметры.
